# Дизайн FoldFinance — «Obsidian»

Тёмный, тихий, точный. Цифры — заголовки, один лаймовый акцент на главное действие, панели
по шарниру. Источник: артборды `docs/design-v2/` (`System`, `Main`, `Review`, `Add`, `Overview`,
`History`, `Analytics`, `Tabletop`). Код токенов — `ui/theme` (`Palette.kt`, `Type.kt`, `Shapes.kt`),
общие компоненты — `ui/components` (`Obsidian.kt`, `MoneyText`, `TransactionRow`, `CategoryChip`).

## Цвет

Тёмная тема — основная. Светлая — согласованный аналог той же структуры (фон → панель →
карточка → поле), а не инверсия.

|---|---|---|---|
| `ink` | `#08080A` | `#EEEEEA` | фон окна |

- Расходы — нейтральным цветом текста, со знаком «−» в строках. Доход — зелёный «+», возврат —
  мягкий нейтральный «+» (уменьшает расходы, не доход), перевод между своими — приглушённый.
- Выбор: мягкая лаймовая заливка (`accentSoft`, 14 %) + лаймовая граница (`accentLine`, 40 %).
- Категории — 10 цветов System-доски (`PaletteTokens.DarkCategories`), в светлой теме — те же тона
  глубже. Сохранённые цвета прежней палитры по-прежнему узнаются как слоты (`LegacyCategories`).
- Dynamic color — опция в настройках (выкл. по умолчанию); фирменные роли остаются фиксированными.
- Старые имена (`saffron`, `mint`, `alert`…) — алиасы новых ролей для кода вне `ui/`.

## Типографика

- **Onest** (OFL) — всё, включая суммы. **JetBrains Mono** (OFL, `res/font`) — только исходный
  текст SMS/push. Табличные цифры (`tnum`) везде, разделитель групп — неразрывный пробел.
- Сумма 48–60 / 600 / −4.5 % (`MoneyStyle.Display`, `Hero`; 42 — карточка проверки, 30 —
  выбранный день, 22 — плитки); копейки 60 % размера, знак валюты в полный размер, но тихим цветом.
- Заголовок 22 / 600 (`headlineMedium`; «Проверка» на внешнем — 28), строка 15 / 500
  (`FoldTextStyles.row`), подпись 12.5 / 400 (`caption`), надпись 12 / caps +4 % (`Overline`),
  подписи навигации 11.5.

## Форма и касание

- Радиусы: 12 чипы · 14 поля и иконки строк · 16 клавиши и кнопки · 22 FAB · 24 плитки ·
  28 панели (`FoldShapes`); карточка проверки — 30.
- Тач-цель ≥ 44 dp (визуально 36-dp чипы получают 48-dp зону касания). Главные действия внешнего
  экрана — 54–64 dp в нижней трети: FAB 62 dp с кольцом цвета фона, круглые 64-dp кнопки проверки,
  «Сохранить» 54 dp.
- Зазор у шарнира — 16 dp (8 + 8, `TwoPaneDefaults.SeamClearance`); перфорированный «шов» прежней
  системы выключен.

## Раскладки

Внешний экран (Compact, одна рука): нижняя навигация из 5 пунктов (Обзор, История, Аналитика,
Проверка с бейджем, Настройки; «Подписки» — строкой на Главной и в Настройках).

```
┌───────────────────┐
│ Четверг, 5 ноября │
│ Ноябрь        (⌕) │
│ Потрачено за месяц│
│ 23 640 ₽          │  48 / 600
│ +95 000 ₽ доход   │
│ ▂▅▁▇▃▁▁▁▁▁▁▁      │  дни месяца, сегодня — лайм
│ [Сегодня][Провер.]│  плитки 24 dp
│ Последние     Все │
│ ⬚ Пятёрочка −1 500│
│              (+)  │  FAB 62 dp
│ ▦  ◷  ▮  ☑³  ≡   │
└───────────────────┘
```

Внутренний экран (книжная поза): rail с лаймовым «+» сверху, две панели 28 dp по шарниру.

```
┌────┬──────────────┐ ┌──────────────┐
│ +  │ Ноябрь 2026 ⌄│ │ Операции   ⌕ │
│ ▦  │ Потрачено    │ │ [Продукты ×] │
│ ◷  │ 23 640 ₽     │ │ СЕГОДНЯ      │
│ ▮  │ ▂▅▁▇ (кат.)  │ │ строки       │
│ ☑  │ ▬▬▬▬ доли    │ │ …            │
│ ≡  │ категории    │ │              │
└────┴──────────────┘ └──────────────┘
                    16 dp = шарнир
```

- История: список и деталь — две панели `ListDetailPaneScaffold`, граница на шарнире.
- Аналитика: FLAT — панель графика шире (~62 %), панели в 16 dp; при HALF_OPENED / `isSeparating`
  (`AppLayout.Book.separating`) граница переезжает на шарнир.
- Tabletop: верх — сумма и график на фоне (смотреть), низ — панель с верхними углами 28 dp:
  период, фильтры, список (трогать); навигация — внизу.

## Принципы

1. **Цифры — это заголовки.** Самое крупное на экране — сумма; всё остальное тихое.
2. **Один акцент.** Лайм — только главное действие и активный выбор. Янтарь — только проверка.
3. **Панели по шарниру.** Ничего не пересекает шарнир; между панелями 16 dp.
4. **Движение отвечает на действие.** Пружины (spatial: damping 0.8, stiffness 380; effects — без
   отскока). Свайп карточки — физическая пружина + haptic. При «Убрать анимацию» — мгновенно.
5. **Пустое состояние — приглашение к действию.** Никаких фиктивных данных.
6. **Тексты.** Глаголы действия: «Добавить», «Подтвердить», «Сохранить · 1 250 ₽». Ошибки
   говорят, что случилось и как исправить.
