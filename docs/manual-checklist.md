# Ручная проверка на Galaxy Z Fold 8

Отмечайте результат и, если что-то не так, что именно произошло.

## Установка и доступы
- [ ] APK ставится; при первом запуске — онбординг с объяснением каждого доступа.
- [ ] SMS: «Сведения о приложении → ⋮ → Разрешить ограниченные настройки», затем доступ выдаётся, повторная проверка проходит.
- [ ] Уведомления: доступ выдаётся тем же путём; статус слушателя в настройках — «подключён».
- [ ] Батарея → «Приложения без спящего режима» — инструкция открывается.

## Диагностика окна (этап 0) — вписать числа в CLAUDE.md
- [ ] Внешний экран: widthDp × heightDp, size class.
- [ ] Внутренний экран: widthDp × heightDp, size class, FoldingFeature (bounds, state, orientation).
- [ ] Tabletop: состояние HALF_OPENED, ориентация шарнира HORIZONTAL.

## Складывание
- [ ] Сценарий 1: открыть операцию на внешнем → разложить → список слева, эта операция справа.
- [ ] Сценарий 2: на внутреннем открыть деталь → сложить → на внешнем деталь, «Назад» — к списку.
- [ ] Фильтры, период, позиция скролла и черновик ручного ввода переживают сложение.
- [ ] «Параметры разработчика → Не сохранять действия»: свернуть и вернуться — состояние на месте.
- [ ] Tabletop: график сверху, управление снизу, ничего не пересекает шарнир.
- [ ] Split-screen и pop-up окно Samsung: раскладка выбирается по размеру окна.
- [ ] Граница панелей на внутреннем экране совпадает с шарниром.

## Данные
- [ ] Первичное сканирование SMS: прогресс, можно свернуть, итог «просканировано / найдено».
- [ ] Повторное сканирование не создаёт дублей.
- [ ] Новая SMS банка появляется в ленте; та же операция из push не дублируется.
- [ ] Возврат уменьшает расходы категории и не попадает в доходы.
- [ ] Перевод между своими картами не попадает в итоги.
- [ ] Остаток показан как «Остаток *1234 на ЧЧ:ММ».

## Безопасность
- [ ] Блокировка по биометрии/PIN при запуске и после таймаута в фоне.
- [ ] FLAG_SECURE: в списке недавних приложений содержимое скрыто; скриншот запрещён.
- [ ] Экспорт в файл → удалить приложение → установить → импорт с паролем → данные на месте.
- [ ] Неверный пароль при импорте — понятная ошибка, данные не повреждены.

## После перезагрузки телефона
- [ ] Слушатель уведомлений переподключается; дельта-скан SMS подхватывает пропущенные.
