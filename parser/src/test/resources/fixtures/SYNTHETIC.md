# Все фикстуры синтетические

Все файлы `<bank>/NNN.txt` + `NNN.expected.json` в этой папке **синтетические**. Они составлены
по общеизвестному виду банковских SMS и push-уведомлений, а **не** по реальным сообщениям
пользователя. Реальных образцов на момент этапа 1 не было (`raw/` пуст).

Что это значит:

- Тексты обезличены и выдуманы: маски карт (`*1234`, `*5678`, `*9012`, `*4321`), суммы, имена
  (`ИВАН И.`, `ООО РОМАШКА`) и мерчанты не относятся к реальным людям и операциям.
- Точный формат конкретного банка (порядок полей, сокращения, знаки валют) может отличаться от
  настоящего. Фикстуры проверяют логику парсера (сумма, валюта, направление, вид, комиссия,
  остаток, маски, NotFinancial/Uncertain), а не соответствие реальному формату банка.
- **Совкомбанк и ВБ Банк:** адреса SMS-отправителей (`Sovcombank`, `SOVCOMBANK`, `Halva`,
  `WB Bank`, `WBBank`, `Wildberries`) и имена пакетов приложений не проверены на устройстве.
  Для Сбербанка и Т-Банка не проверены имена пакетов. См. KDoc `KnownBankSources`.

## Когда появятся реальные образцы

1. Обезличенные сообщения кладутся в `raw/<bank>/` (см. `raw/README.md`).
2. **Сначала фикстура, потом код:** для каждого образца создаётся `<bank>/NNN.txt` +
   `NNN.expected.json` с ожидаемым результатом, ожидания согласуются с пользователем.
3. Только после этого правится парсер, пока `FixturesTest` не станет зелёным.
4. Синтетические фикстуры, которые противоречат реальному формату, удаляются или исправляются.
5. Если результат на сохранённых сообщениях может измениться — увеличить `PARSER_VERSION`.

## Формат `NNN.expected.json`

```json
{
  "description": "что проверяет кейс",
  "meta": { "channel": "SMS|PUSH", "sender": "900", "receivedAt": "2026-11-05T12:35:00+03:00", "title": "заголовок push (необязательно)" },
  "result": "PARSED | NOT_FINANCIAL | UNCERTAIN",
  "parserId": "sber",
  "operations": [ { "amountMinor": 150000, "currency": "RUB", "direction": "EXPENSE", "kind": "PURCHASE",
                    "merchant": "PYATEROCHKA", "cardMask": "*1234", "counterpartyCardMask": null,
                    "occurredAt": "2026-11-05T12:34:00+03:00", "needsReview": false } ],
  "balance": { "amountMinor": 1023456, "currency": "RUB", "cardMask": "*1234" },
  "reason": "только для UNCERTAIN, см. UncertainReasons",
  "partial": "только для UNCERTAIN: операция в том же формате или null"
}
```

`needsReview` = `confidence < ParsedOperation.NEEDS_REVIEW_THRESHOLD`. Время в `occurredAt`
трактуется в поясе `Europe/Moscow` (так настроен `FixturesTest`). `.txt` хранится в UTF-8 с LF,
в конце файла один перевод строки (он отбрасывается); NBSP и тонкие пробелы сохраняются как есть.


## Реальные форматы

- `sber/011` — реальная SMS пользователя («Счёт карты MIR-…», покупка по СБП), 2026-11-05.
- `sovcombank/011` — реальная SMS пользователя («ХАЛВА пополнена … https://scb.im/hva»), 2026-11-05.

Обе обезличены: цифры карты, баланс и сумма пополнения заменены, формат сохранён. Исходники — `raw/sber/001.txt`, `raw/sovcombank/001.txt`.
