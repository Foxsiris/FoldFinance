# Реальные образцы сообщений

Сюда кладутся **обезличенные** реальные SMS и тексты push-уведомлений банков. Тесты эту папку
не читают: это исходный материал, по которому пишутся фикстуры (`../<bank>/NNN.txt` +
`NNN.expected.json`).

## Куда класть

```
raw/
  sber/        # Сбербанк, SMS от 900 и push приложения
  tbank/       # Т-Банк
  sovcombank/  # Совкомбанк / Халва
  wbbank/      # ВБ Банк (Wildberries Bank)
  other/       # прочие банки
```

## Как класть

- Один файл — одно сообщение, UTF-8, имя `NNN.txt` (`001.txt`, `002.txt`, …).
- Первой строкой — источник: `sender: 900` (SMS) или `package: <имя пакета>` (push);
  для push второй строкой — `title: <заголовок>`. Затем пустая строка и текст как есть.
- Пробелы и знаки не «исправлять»: неразрывные и тонкие пробелы, `₽`, `−` важны для парсера.
  Удобнее всего копировать из приложения «Сообщения» или истории уведомлений Samsung.
- Чем больше разных видов, тем лучше: покупка, перевод (себе и другому), входящий перевод,
  возврат, комиссия, валютная покупка, зачисление зарплаты, снятие наличных, пополнение,
  подписка, отказ, реклама, код подтверждения.

## Обезличивание (обязательно)

- Номер карты/счёта: оставить формат, заменить цифры (`*1234`, `VISA1234`).
- Имена, телефоны, адреса, номера договоров: заменить (`ИВАН И.`, `+7 900 000-00-00`).
- Суммы и остатки можно оставить или изменить — формат записи важнее значения.
- Коды подтверждения заменить на любые другие цифры.
